# Distributed Job Queue - Built with Claude

A Java/Spring Boot distributed job queue built as an independent software engineering practice project.

## Purpose

This project explores asynchronous job processing using:

* Java
* Spring Boot
* PostgreSQL
* Redis
* Docker
* JUnit 5
* Testcontainers
* CI/CD

The system allows jobs to be submitted through a REST API, persisted, queued, and processed asynchronously by workers.

The project is intended to demonstrate practical experience with:
